# Teste de Responsividade

Projeto simples desenvolvido para praticar responsividade com HTML, CSS e JavaScript. O objetivo é testar como o layout se adapta a diferentes tamanhos de tela, como computadores, tablets e celulares.

## Tecnologias utilizadas

- **HTML5:** estrutura da página.
- **CSS3:** estilos, Flexbox, Grid e media queries.
- **JavaScript:** abertura e fechamento do menu em telas menores.

## O que foi praticado

- Adaptação do layout nos pontos de quebra de 1024px, 768px e 425px.
- Organização dos blocos em diferentes quantidades de colunas conforme a largura da tela.
- Menu responsivo com botão para exibir e ocultar os links.
- Mudança da cor de fundo com media queries em uma página de teste (`media.html`).

## Como visualizar

Abra o arquivo `index.html` no navegador e redimensione a janela para observar as mudanças no layout. Também é possível usar o modo de dispositivos nas ferramentas de desenvolvedor do navegador.

Para visualizar o teste de cores por tamanho de tela, abra o arquivo `media.html`.
